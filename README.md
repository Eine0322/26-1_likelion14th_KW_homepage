### Web: 멋쟁이사자처럼 14기 광운대 홈페이지

<br/> [<img src="https://img.shields.io/badge/프로젝트 기간-2026.01.05~2026.01.07-orange?style=flat&logo=&logoColor=white" />]()

</div> 


## 📍 프로젝트 개요

광운대학교 멋쟁이사자처럼을 홍보, 소개하기 위한 홈페이지입니다. 진행한 프로젝트 및 각 파트를 소개합니다.

<br/>

## 📍 주요 기능
- 참여 프로젝트 소개
- 트랙 소개
- 커리큘럼 소개

<br/>
